# 离线订阅交付与 Key 零留存

## 管理员流程

1. 在“订阅管理”按院校、档位和数量签发 Key，并下载一次性 Excel 回执。
2. 在“订阅交付”导入该 Excel。应用仅在本次请求内存中提取 Key，并使用哈希和 HMAC 指纹核验其可用性及院校管理范围。
3. 选择可用 Key。导出 PDF 时可为每个 Key 指定同校、已验证的学生或教师账户，也可选择“通用 PDF”；直接激活必须指定账户。
4. 选择其一：
   - **直接激活用户**：界面会禁用仍处于有效高级订阅周期的账户；服务器在一个数据库事务中再次校验目标、写入订阅并消耗 Key。任一项失败则整体回滚。
   - **导出 PDF**：生成仅含所选通知单的 ZIP 下载；Key 保持未激活，管理员通过受控渠道自行发送。

## Key 与文件安全边界

- `premium_subscription_keys` 仅保存密码哈希、HMAC 指纹、院校、档位和状态；不保存 Key 明文或可逆密文。
- Excel 上传受 Nginx 512 KB 限制，低于上传中间件的磁盘溢写阈值；应用随后在内存中解析并立即丢弃字节内容。
- 校验、激活与 PDF 导出请求均设置或使用 `no-store` 缓存策略；导出的 PDF/ZIP 不在服务器文件系统或数据库留存。
- PDF 采用中英双语黑白、加重宋体与无衬线的机读卡式版面，包含受益人、账户、适用院校、档位、Key、权益周期和签发日期，并以 QR、Code 128 和 Code 93 编码同一 Key。编码仅便于读取，不构成额外认证。
- 通用 PDF 固定标记“通用 / 不指定”的学生、教师和账户字段，并保留院校、档位、权益周期与 Key；它不能用于直接激活。
- 未激活 Key 可被授权管理员收回；已直接激活的 Key 不可回收。
