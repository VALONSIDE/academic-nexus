# 工作台通知与 AI 办理卡片

## 通知

通知与业务变更在同一事务提交。每条通知记录事件类型、接收账户、工作台、操作人、时间、已读状态和业务对象。订阅通知会附带院校及适用的档位、数量或额度变化。通知中不保存 Key 明文、登录凭据或私密联系方式。

用户点击工作台右上角的铃铛打开通知中心。红点表示存在未读消息。通知中心可筛选未读和全部标为已读，概览展示最新五条，历史页支持分页。点击通知打开全局 Dialog，显示事件、时间、对象和相关数据，同时标为已读。「前往处理」按下表定位业务页面。

| 业务事件 | 接收方 | 处理入口 |
| --- | --- | --- |
| 双选开放、关闭 | 有效学生和导师 | 所属工作台的双选页 |
| 学生发起或取消申请、拒绝邀请 | 相关导师 | 学生匹配页，定位相关人 |
| 导师发出或撤回邀请、拒绝申请 | 相关学生 | 导师匹配页，定位相关人 |
| 双选确认或管理员释放记录 | 双方 | 各自的双选页，定位相关人 |
| 学生确认其他导师，原待处理关系关闭 | 原待处理导师 | 学生匹配页，定位相关人 |
| 个体额度、特例或导师确认模式更新 | 受影响师生 | 各自的双选页 |
| 订阅额度分配、Key 签发或回收 | 同院校其他在任管理员 | 订阅管理，定位对应院校 |
| 高级订阅激活 | 激活账户 | 本人订阅页 |
| 批量直接交付 | 同院校其他在任管理员 | 订阅交付页 |
| 超级管理员发送定向额度、分配、签发或交付提醒 | 所选院校在任管理员 | 对应院校的订阅管理或交付页 |
| 院校管理员指派或撤销 | 被调整的账户 | 指派进入管理工作台，撤销后进入师生工作台 |
| 单个或批量资源配额调整 | 对应导师 | 我的资源 |

余额和历史按院校权限读取。定向提醒的发送和接收人查询仅向超级管理员授权，目标必须是该院校的在任管理员。同一发送者对同一接收人、院校和类型的未读提醒会合并。导出交付 PDF 写入历史。对自己发起且已有即时反馈的操作通常省略自我通知。

## AI 办理卡片

卡片放在对应 AI 回答后，使用全局 Button，展示业务、对象姓名、当前状态、办理按钮和画像详情入口。AI 双选顾问可从候选页带入已选对象，也可以根据对话中明确的双选意图和唯一匹配的同校对象生成卡片。

| 当前状态 | 可以展示的动作 |
| --- | --- |
| 学生尚未申请且有额度 | 发送双选申请 |
| 导师尚未邀请且有名额 | 发送导师邀请 |
| 学生收到待处理导师邀请 | 接受导师邀请 |
| 导师收到待处理学生申请且有名额 | 确认学生申请 |

服务端根据双方角色、院校、画像、双选开放状态和额度生成结构化卡片。模型收到可用动作和文案规则，只负责解释。资料不足、对象不唯一或业务条件不满足时，只显示聊天回答。普通和流式回答都在消息成功保存后呈现卡片。卡片随同一条助手消息持久化，刷新后仍可查看。

点击按钮后，服务端再次核对会话归属、消息、对象和当前业务状态，再调用双选服务。成功后显示已提交或已确认，重复点击返回原结果。状态或额度发生变化时，卡片提示回双选页核对。双选通知与状态变化一起提交。

## 额度统计口径

- 空闲额度是当前尚可签发的库存。「累计签发」包括仍待激活、使用中、额度用完、周期已结束和已回收。
- 使用中要求 Key 对应当前有效订阅周期且余额大于零。活跃周期余额归零计入「额度用完」，周期结束后计入「周期已结束」。
- 签发、激活及回收历史可从旧 Key 的已有时间记录读取。额度调整和交付导出事件从迁移上线后开始记录。
- 学生的特例豁免待处理志愿数，仍只能确认一位导师。导师特例豁免已确认与已发邀请的名额限制。已占用数量高于新限额时，系统要求先处理或释放相关记录。
- 管理员可分别设置个体上限、豁免和导师确认方式。清空上限会采用全局额度，恢复统一规则会同时移除豁免并将导师确认方式恢复为手动。先选先得仍受当前可用名额约束。
- 超级管理员可以调整院校订阅库存和全局双选规则。院校管理员管理授权院校的双选记录、个体规则以及订阅签发和交付。
